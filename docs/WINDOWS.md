# Запуск Core Presentation на Windows

## Самый простой способ

1. Установите Node.js 22 или новее, если он ещё не установлен.
2. Скачайте репозиторий или выполните git clone https://github.com/kuminovvv/core-presentation.git. Если SSH-клонирование зависает, используйте HTTPS.
3. **Дважды щёлкните start-core-presentation.cmd** в папке проекта.

Скрипт проверит зависимости, соберёт актуальную веб-версию, запустит локальный сервер и автоматически откроет браузер по адресу **http://127.0.0.1:4173/**. Не закрывайте окно консоли, пока работаете с редактором. Ctrl+C останавливает сервер.

### Если не хочется использовать скрипт

Откройте PowerShell в папке проекта:

```powershell
npm ci
npm run build
npm start
```

Затем перейдите на http://127.0.0.1:4173/.

### Как пользоваться

Создайте проект кнопкой **+**, добавьте слайд или выберите готовый макет. Дважды щёлкните по тексту для редактирования. Перетаскивайте объекты, меняйте размер маркерами и поворачивайте верхним круглым маркером. Выбирайте фон, переходы и анимации через панель свойств. Данные сохраняются автоматически в `presentations/<имя-проекта>/presentation.json`, а при конфликте с правками ИИ редактор предложит сохранить копию.

Для показа используйте **Предпросмотр → Полный экран**; для передачи презентации — **Экспорт HTML** или **PDF**. Экспорт HTML работает в браузере без установленного редактора. PDF требует Google Chrome.

### Подключение Codex

В репозитории предусмотрен MCP-сервер. Настройте его по инструкции [MCP.md](MCP.md) для локального stdio или [MCP_HTTP.md](MCP_HTTP.md) для защищённого HTTP MCP., затем создавайте или меняйте слайды прямо через ИИ-агента. Открытый веб-редактор автоматически подхватит обновления.

### Хранение и восстановление

Активные проекты находятся в `presentations/`. Архивирование через меню проекта не удаляет файлы безвозвратно: они перемещаются в `presentations/.trash/`. Для восстановления остановите сервер и верните папку проекта из `.trash` обратно в `presentations/`, при необходимости переименовав её в короткое имя латиницей.

Локальный демонстрационный документ автоматически сохраняется в хранилище браузера. Для резервного копирования используйте **Сохранить JSON**.

**Важно:** приложение слушает только `127.0.0.1`. Не открывайте локальный API через публичный reverse proxy без отдельной аутентификации и TLS. Непроверенный HTML/JavaScript в презентации может содержать вредоносный код — открывайте только доверенные проекты.
